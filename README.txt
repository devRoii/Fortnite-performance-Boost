Hi! in this folder you'll find a couple files that will boost your FPS and reduce imput lag.

The 'RoiCleanUp' is a simple tool that will delete every bloatware / useless file in your pc. you might gain little perfomance from it, depending how much is your Windows clean.
You should run it at least once a week.

If you dont know what a GameUserSettings is,
make sure to watch the tutorial i made: https://www.twitch.tv/videos/2874326722

All the GameUserSettings are setted with the best config possible to gain performance.

The brightness is set to 150% by default, while the view distance to near.

To change those:
1- Uncheck read-only in file's properties
2- For brightness, scroll to DisplayGamma=2.700000
   2.70 =150%, so 2.60 will be 140%, 2.50 =130%, etc..
3- Then scroll all the way down to sg.ViewDistanceQuality=0
   0 = near | 1 = medium | 2 = far | 3 = epic
4- When you're done, save the file and check Read-only, again
